Cara Publish Online (Mendapatkan URL Publik)

Karena saya tidak bisa menyediakan hosting server dengan URL langsung, Anda perlu mengupload file HTML ini ke platform gratis berikut untuk mendapatkan link yang bisa diakses publik:

Opsi 1: GitHub Pages (Paling Mudah & Gratis)

  1. Buat akun di github.com
  2. Buat repository baru (misal: portfolio-feri)
  3. Upload file portfolio_feri_yansah.html ke repository
  4. Rename file menjadi index.html
  5. Masuk ke Settings > Pages
  6. Pilih branch main dan folder root
  7. Klik Save
  8. URL Anda akan muncul: https://username.github.io/portfolio-feri/

Opsi 2: Netlify (Drag & Drop)

  1. Buka netlify.com
  2. Daftar dengan email/Google
  3. Drag & drop file HTML ke dashboard Netlify
  4. URL otomatis dibuat (contoh: https://feri-portfolio-123.netlify.app)

Opsi 3: Vercel

  1. Buka vercel.com
  2. Import dari GitHub atau upload file langsung
  3. Deploy otomatis dengan URL gratis

Cara Publish dengan Foto

Agar foto muncul di portfolio online, kedua file harus diupload bersamaan ke folder yang sama di platform hosting:

GitHub Pages

  1. Download kedua file di atas
  2. Buat repository baru di github.com
  3. Upload portfolio_feri_yansah.html (rename jadi index.html) dan Foto_F.jpg ke repository yang sama
  4. Aktifkan GitHub Pages di Settings
  5. URL: https://username.github.io/nama-repo/

Netlify (Drag & Drop)

  1. Buat folder di komputer Anda (misal: portfolio-feri)
  2. Copy kedua file ke dalam folder tersebut
  3. Buka netlify.com, drag & drop seluruh folder ke dashboard
  4. URL otomatis dibuat

Vercel

  1. Buat folder berisi kedua file
  2. Upload folder ke Vercel
  3. Deploy otomatis
Penting: Jangan pisahkan file HTML dan foto. Foto harus berada di folder yang sama dengan file HTML agar tampil dengan benar. Jika ingin mengganti nama foto, pastikan juga mengubah src="Foto_F.jpg" di dalam file HTML.
